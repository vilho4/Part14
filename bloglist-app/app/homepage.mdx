# Bloglist

Welcome to Bloglist!

## About

Bloglist is an application for sharing and discovering interesting blogs.

This is an example app for [Full Stack Open Next.js](https://courses.mooc.fi/org/uh-cs/courses/full-stack-open-nextjs).

See the [source code](https://github.com/fullstack-hy2020/nextjs-notes) for the example application.

## Features

- Browse blogs
- Add your own blogs
- Save blogs to your reading list
- Keep track of blogs you have read
